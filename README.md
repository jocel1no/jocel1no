## 🚀 Projetos em destaque

### ⚡ TextMagic: extensão para navegador

<a href="https://github.com/jocel1no/textmagic">
  <img src="assets/textmagic-banner.png" alt="TextMagic: atalhos de texto que viram respostas completas em qualquer site">
</a>

Atalhos de texto que viram respostas completas em qualquer site, inclusive no WhatsApp Web.
A pessoa digita `@atalho` e o texto inteiro aparece na hora, com variáveis como `{nome}` e `{saudacao}` preenchidas automaticamente.

- **Textos prontos e atalhos**: uma biblioteca de respostas organizada por categoria
- **Imagens em 1 clique**: tabelas, comprovantes e tutoriais colados direto na conversa
- **Wiki, links e notas** da empresa sempre à mão
- **Painel do gestor**: edita uma vez e a atualização chega para toda a equipe
- **Segurança**: login via OAuth (a senha não passa pela extensão) e sessão única por operador

**Tecnologias:** JavaScript (extensão Chrome Manifest V3) · Go (API) · Flutter Web (painel)

🔗 [Conheça o projeto](https://github.com/jocel1no/textmagic) · 🧩 [Chrome Web Store](https://chromewebstore.google.com/detail/textmagic/eodaekpohacpogcnojdcaemdgcngcppm) · 🌐 [textmagic.app.br](https://textmagic.app.br)
